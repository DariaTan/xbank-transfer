# Сопоставление колонок xbank → MBD методом semi-relaxed FGW

Нужно для каждого поля MBD выбрать, из какой колонки xbank брать данные. Одну колонку xbank разрешено использовать несколько раз.

Описание соответствует реализации в `column_profiles_vFGW.py`. Модуль самостоятельный: схемы, чтение данных, статистики паспортов, различие D, оптимизатор и тестбеды находятся в одном файле. Импортов других модулей проекта нет; нужны библиотеки `duckdb`, `numpy`, `pandas` и `scikit-learn`. Ниже паспортная часть сразу записана через **различие D**: чем оно меньше, тем ближе паспорта двух колонок.

## Шаг 1. Берём данные двух банков

Например, по 2 млн транзакций xbank и MBD при `--sample-rows 2000000`. Строки между банками не сопоставляем: это разные транзакции и люди. Число строк с каждой стороны может различаться.

Обозначения:

- $X_i$ — признак xbank с индексом $i$;
- $Y_j$ — признак MBD с индексом $j$;
- $i,k$ — индексы признаков xbank;
- $j,l$ — индексы признаков MBD;
- $A$ — произвольная колонка одного из банков;
- $R_A$ — общее число строк в выборке для колонки $A$;
- $N_A$ — число валидных значений в ней;
- $U_A$ — число уникальных валидных значений.

Например, $X_i$ — `col_2`, а $Y_j$ — `event_type`.

В числовых колонках пропуски, NaN и бесконечности не входят в валидные значения. В категориальных колонках пропуски исключаются; для вещественных категориальных колонок также исключаются NaN и бесконечности.

`--sample-rows 0` означает использование всех строк выбранного источника. Значение `--seed` фиксирует случайную выборку; при `--threads 1` она воспроизводима при одинаковых входных данных. Время и идентификатор клиента в формулы ниже не входят. Пара `col_1 → event_time` добавляется отдельно как фиксированная.

## Шаг 2. Описываем каждую колонку статистиками

Набор статистик называется **паспортом колонки**. Статистики распределения считаются по валидным значениям, доля пропусков — по всем строкам.

### 2.1. Доля пропусков

Обозначение: $r_{\mathrm{null}}(A)$ — доля невалидных значений колонки $A$.

$$
r_{\mathrm{null}}(A)=1-\frac{N_A}{R_A}.
$$

Для пустой выборки код задаёт эту долю равной 1. Если валидных значений нет, колонка не участвует в допустимых парах.

### 2.2. Категориальная колонка

Обозначения:

- $c$ — одна из наблюдаемых категорий;
- $n_c$ — число появлений категории $c$;
- $p_c$ — её частота среди валидных значений;
- $top1(A)$ — доля самой частой категории;
- $H_{\mathrm{norm}}(A)$ — нормированная энтропия колонки.

$$
p_c=\frac{n_c}{N_A},
\qquad
 top1(A)=\max_c p_c.
$$

$$
H_{\mathrm{norm}}(A)=
\begin{cases}
\displaystyle\frac{-\sum_c p_c\log_2p_c}{\log_2U_A}, & U_A>1,\\
0, & U_A=1.
\end{cases}
$$

При равномерных частотах энтропия равна 1. При преобладании одной категории она ближе к 0. Здесь учитываются все наблюдаемые категории, без объединения редких.

Основные характеристики для сравнения категориальных колонок:

$$
[U_A,\ H_{\mathrm{norm}}(A),\ top1(A),\ r_{\mathrm{null}}(A)].
$$

### 2.3. Числовая колонка

Обозначения:

- $p$ — уровень квантиля;
- $Q_A(p)$ — квантиль уровня $p$ по валидным значениям колонки $A$;
- $\mathcal P$ — набор уровней квантилей;
- $K$ — число этих уровней;
- $b_A$ — размах, используемый для нормировки;
- $z_A(p)$ — нормированное значение квантиля;
- $r_{\mathrm{zero}}(A)$ — доля нулей среди валидных значений.

Используются 21 квантиль:

$$
\mathcal P=\{0.01; 0.05\to0.95\text{ с шагом 0.05}; 0.99\},
\qquad K=21.
$$

Основная нормировка:

$$
b_A=Q_A(0.95)-Q_A(0.05),
\qquad
z_A(p)=\frac{Q_A(p)-Q_A(0.50)}{b_A}.
$$

Если этот размах нулевой, последовательно пробуем:

1. $b_A=Q_A(0.99)-Q_A(0.01)$;
2. максимум минус минимум валидных значений;
3. если и полный размах равен нулю, задаём все $z_A(p)=0$.

и также мы смотрим на: 
$$
r_{\mathrm{zero}}(A)=
\frac{\text{число валидных значений, равных нулю}}{N_A}.
$$

Нормированный вектор квантилей сохраняется при сдвиге и умножении значений на положительную константу. Доля нулей при сдвиге может измениться, поэтому всё числовое различие не обязательно сохраняется.

В паспорта также сохраняются диагностические статистики: 
- доля уникальных значений, 
- для категориальных — доля трёх самых частых категорий, 
- для числовых — минимум, максимум, среднее, стандартное отклонение и доля целочисленных значений. 

Они непосредственно в формулы различия ниже **не входят.**

## Шаг 3. Считаем различие паспортов D

Обозначения:

- **$D_{ij}$ — различие паспортов $X_i$ и $Y_j$;**
- $d_U$ — различие числа категорий с поправкой на объём выборок;
- $d_H$ — различие нормированных энтропий;
- $d_{\mathrm{top1}}$ — различие долей самых частых категорий;
- $d_{\mathrm{null}}$ — различие долей пропусков;
- $d_Q$ — различие нормированных квантильных векторов;
- $d_{\mathrm{zero}}$ — различие долей нулей.

Все эти различия относятся к одной паре $X_i,Y_j$.

### 3.1. Категориальные пары

$$
d_H=|H_{\mathrm{norm}}(X_i)-H_{\mathrm{norm}}(Y_j)|,
$$

$$
d_{\mathrm{top1}}=|top1(X_i)-top1(Y_j)|,
$$
$$
d_{\mathrm{null}}=|r_{\mathrm{null}}(X_i)-r_{\mathrm{null}}(Y_j)|.
$$

Для поправки на объём выборок обозначим:

- $\Delta_U$ — логарифм отношения числа уникальных значений;
- $\Delta_N$ — логарифм отношения числа валидных наблюдений;
- $h$ — послабление за различие объёмов выборок.

$$
\Delta_U=\log_{10}\frac{U_{X_i}}{U_{Y_j}},
\qquad
\Delta_N=\log_{10}\frac{N_{X_i}}{N_{Y_j}}.
\qquad
h=
\begin{cases}
|\Delta_N|, & \Delta_U\Delta_N>0,\\
0, & \text{иначе},
\end{cases}
\qquad
$$

$$
d_U=\frac{\max(0,|\Delta_U|-h)}{0.75}.
$$

Послабление применяется, когда больше наблюдений сопровождается большим числом категорий. Это эвристическая поправка. Если $d_U>1$, пара исключается.

Для допустимой категориальной пары:

$$
\boxed{D_{ij}=0.35d_U+0.30d_H+0.20d_{\mathrm{top1}}+0.15d_{\mathrm{null}}.}
$$

Например, при $d_U=0.2$, $d_H=0.1$, $d_{\mathrm{top1}}=0.05$ и $d_{\mathrm{null}}=0$:

$$
D_{ij}=0.35\cdot0.2+0.30\cdot0.1+0.20\cdot0.05=0.11.
$$

**ВАЖНО: коэффиценты здесь эвристические (подобранные руками).** 

### 3.2. Числовые пары

Обозначение: $\ell_Q$ — среднее абсолютное различие нормированных квантилей.

$$
\ell_Q=\frac1K\sum_{p\in\mathcal P}|z_{X_i}(p)-z_{Y_j}(p)|,
\qquad
d_Q=\frac{\ell_Q}{1+\ell_Q}.

$$

$$
d_{\mathrm{zero}}=|r_{\mathrm{zero}}(X_i)-r_{\mathrm{zero}}(Y_j)|.
$$

Для допустимой числовой пары:

$$
\boxed{D_{ij}=0.70d_Q+0.15d_{\mathrm{zero}}+0.15d_{\mathrm{null}}.}
$$

**ВАЖНО: коэффиценты здесь эвристические (подобранные руками).** 

### 3.3. Исключаем недопустимые пары

Пара допускается, только если:

- совпадают типы `categorical` / `numeric`;
- в обеих колонках есть валидные значения;
- для категориальных выполнено $d_U\le1$;
- для числовых совпадают подтипы: одно, два или больше двух уникальных значений;
- различие не превышает настроенный порог: по умолчанию `--max-distance 0.70`, то есть $D_{ij}\le0.70$; значение $D_{ij}=1$ всегда исключено.

Числовой подтип с более чем двумя значениями называется в коде `continuous`, но это не проверка непрерывности распределения. Совпадение физических типов `int` / `float` не требуется.

Обозначение: $\mathcal A_j$ — множество допустимых источников xbank для поля MBD $j$.

Если $\mathcal A_j$ пусто, поле получает статус `unfilled` и не участвует в оптимизации. Эти фильтры действуют при любом значении `alpha`.

Пример матрицы различий (условные числа):

| Источник xbank | `event_type` MBD | `src_type11` MBD |
|---|---:|---:|
| `col_2` | 0.04 | 0.16 |
| `col_3` | 0.30 | 0.24 |

Чем меньше клетка, тем ближе паспорта. По этой таблице `col_2` предпочтительнее для обоих полей. Назначения на этом шаге ещё не выбраны.

## Шаг 4. Изучаем связи внутри каждого банка

Для связей берём до 50 тыс. строк каждой стороны при `--structure-rows 100000`. Это подвыборка из строк, использованных для паспортов. Все колонки одной стороны используют общую выборку строк, иначе зависимости потеряются.

`--structure-rows 0` означает все строки паспортной выборки. Связи считаются внутри транзакций, без анализа последовательности событий.

### 4.1. Подготавливаем значения

Для числовых колонок при `--structure-bins 10` строим границы по квантилям уровней `0, 0.1, 0.2, ..., 0.9, 1`. Заменяем значения номерами интервалов. Совпадающие границы объединяем, поэтому интервалов может быть меньше десяти. Это отдельная сетка, не сетка из 21 квантиля паспорта.

Для категориальных колонок при числе категорий более `--max-categories 64` сохраняем наиболее частые категории отдельно, остальные объединяем. Категории с одинаковой частотой на границе отбора объединяются целиком, поэтому групп может быть меньше лимита. Такое объединение применяется только для оценки связей.

### 4.2. Считаем взаимную информацию и расстояние

Обозначения:

- $A,B$ — две подготовленные колонки(признаки) одного банка;
- $u,v$ — их дискретные значения;
- $p(u,v)$ — частота совместного появления значений $u,v$ в одной строке;
- $p_A(u),p_B(v)$ — соответствующие отдельные частоты;
- $H(A),H(B)$ — обычные энтропии, без нормировки на число категорий;
- $I(A;B)$ — взаимная информация;
- $\operatorname{NMI}(A,B)$ — нормированная взаимная информация;
- $C(A,B)$ — структурное расстояние.

Все частоты этой пары считаем по строкам, где обе колонки валидны. В сумме для взаимной информации учитываем только наблюдаемые сочетания с положительной частотой.

$$
H(A)=-\sum_u p_A(u)\log p_A(u),
\qquad
H(B)=-\sum_v p_B(v)\log p_B(v).
$$

$$
I(A;B)=\sum_{u,v}p(u,v)\log\frac{p(u,v)}{p_A(u)p_B(v)}.
$$

$$
\operatorname{NMI}(A,B)=\frac{2I(A;B)}{H(A)+H(B)},
$$
$$
C(A,B)=1-\operatorname{NMI}(A,B).
$$

В этих формулах используется одно и то же основание логарифма. При независимости переменных взаимная информация равна нулю; оценка на конечной выборке может быть ненулевой.

Сильной зависимости соответствует небольшое структурное расстояние. Это мера ассоциации, не причинности и не направления связи.

Обозначения:

- $C^X$ — матрица расстояний между колонками xbank;
- $C^Y$ — матрица расстояний между полями MBD.

$$
C^X_{ik}=1-\operatorname{NMI}(X_i,X_k),
\qquad
C^Y_{jl}=1-\operatorname{NMI}(Y_j,Y_l).
$$

Для расчёта требуется минимум `--min-pairs 60` совместно валидных строк и больше одного значения у каждой колонки на этих строках. Иначе вне диагонали ставится $C=1$. Это условное заполнение неизвестной связи, а не доказанная независимость. Диагональ задаётся равной нулю. Поддержка и пригодность оценки сохраняются отдельно.

После шага 4 готовы три фиксированные матрицы:

| Матрица | Значение клетки |
|---|---|
| $D_{ij}$ | Различие паспортов колонки xbank и поля MBD |
| $C^X_{ik}$ | Расстояние по зависимости между двумя колонками xbank |
| $C^Y_{jl}$ | Расстояние по зависимости между двумя полями MBD |

## Шаг 5. Задаём матрицу назначений и общую потерю FGW

Три исходные матрицы больше не меняются. Подбирается четвёртая матрица — **T**, план переноса.

Обозначения:

- $m$ — число полей MBD с непустым множеством допустимых источников;
- $T_{ij}$ — оптимизируемая масса назначения источника $X_i$ полю $Y_j$;
- $q_j$ — общая масса, выделенная полю MBD $j$;
- $\alpha$ — вес структурной части, от 0 до 1;
- $L_{\mathrm{passport}}(T)$ — суммарная паспортная потеря;
- $L_{\mathrm{structure}}(T)$ — суммарная структурная потеря;
- $F(T)$ — общая потеря всей матрицы назначений.

Далее суммы по $j,l$ относятся только к активным полям MBD; $m>0$. Если активных полей нет, оптимизация не запускается.

### 5.1. Ограничения на T

$$
q_j=\frac1m,
\qquad
T_{ij}\ge0,
\qquad
\sum_iT_{ij}=q_j,
\qquad
T_{ij}=0\quad\text{при }i\notin\mathcal A_j.
$$

Например, при двух полях каждому выделяется масса 0.5. Столбец `[0.3, 0.2]` означает распределение этой массы между двумя источниками в пропорции 60% / 40%. Эти числа не являются значениями транзакций или вероятностями правильного соответствия.

На суммы по строкам ограничений нет. Поэтому одна колонка xbank может получить массу сразу в нескольких столбцах MBD.

Это **semi-relaxed FGW**: фиксировано распределение массы только на стороне MBD. В обычной сбалансированной постановке GW фиксируются обе стороны. План переноса — стандартная переменная метода, а не дополнительная паспортная метрика.

### 5.2. Функция потерь

$$
L_{\mathrm{passport}}(T)=\sum_{i,j}D_{ij}T_{ij}.
$$

$$
L_{\mathrm{structure}}(T)=
\sum_{i,j,k,l}(C^X_{ik}-C^Y_{jl})^2T_{ij}T_{kl}.
$$

$$
\boxed{
F(T)=(1-\alpha)\sum_{i,j}D_{ij}T_{ij}
+\alpha\sum_{i,j,k,l}(C^X_{ik}-C^Y_{jl})^2T_{ij}T_{kl}.
}
$$

Задача — найти допустимую матрицу с минимальной потерей:

$$
\boxed{T^*\in\arg\min_T F(T).}
$$
**Суть:**
- Первая часть штрафует назначения с разными паспортами. 
- Вторая штрафует совместные назначения $X_i\to Y_j$ и $X_k\to Y_l$, если связь между $X_i,X_k$ отличается от связи между $Y_j,Y_l$.

При `--alpha 0` учитываются только паспорта. При `--alpha 1` — только структура, но предварительные фильтры остаются. При `--alpha 0.5` коэффициенты равны.

### Числовой пример: почему может победить большее D

Все числа этого примера условные. Есть два источника $X_1,X_2$, два целевых поля $Y_1,Y_2$, все четыре пары допустимы.

Обозначения: $T_A$ и $T_B$ — два рассматриваемых плана назначений.

| $D$ | $Y_1$ | $Y_2$ |
|---|---:|---:|
| $X_1$ | 0.10 | 0.15 |
| $X_2$ | 0.80 | 0.20 |

Пусть структурные расстояния равны:

$$
C^X=C^Y=\begin{pmatrix}0&1\\1&0\end{pmatrix}.
$$

**Вариант А:** оба поля получают источник $X_1$.

$$
T_A=\begin{pmatrix}0.5&0.5\\0&0\end{pmatrix}.
$$

$$
L_{\mathrm{passport}}(T_A)=0.10\cdot0.5+0.15\cdot0.5=0.125.
$$

Сравниваем расстояние источника до самого себя, $C^X_{11}=0$, с расстоянием между разными целевыми полями, $C^Y_{12}=1$. В сумме учитываются оба направления пары:

$$
L_{\mathrm{structure}}(T_A)=2\cdot(0-1)^2\cdot0.5\cdot0.5=0.5.
$$

**Вариант Б:** $Y_1$ получает $X_1$, а $Y_2$ — $X_2$.

$$
T_B=\begin{pmatrix}0.5&0\\0&0.5\end{pmatrix}.
$$

$$
L_{\mathrm{passport}}(T_B)=0.10\cdot0.5+0.20\cdot0.5=0.15,
\qquad
L_{\mathrm{structure}}(T_B)=0.
$$

При $\alpha=0.5$:

$$
F(T_A)=0.5\cdot0.125+0.5\cdot0.5=0.3125,
$$

$$
F(T_B)=0.5\cdot0.15+0.5\cdot0=0.075.
$$

Из этих двух вариантов FGW предпочитает Б. Его паспортная потеря больше, но структурная меньше настолько, что общая потеря уменьшается. Это сравнение двух планов, не описание полного перебора алгоритмом.

## Шаг 6. Оптимизатор постепенно меняет T

Используется метод Frank–Wolfe с точным поиском шага для квадратичной функции вдоль выбранного направления. По умолчанию выполняются пять запусков (`--n-init 5`).

### 6.1. Начальные планы

Обозначение: $|\mathcal A_j|$ — число допустимых источников для поля $j$.

Первый план равномерный по допустимым источникам:

$$
T_{ij}^{(0)}=
\begin{cases}
q_j/|\mathcal A_j|,&i\in\mathcal A_j,\\
0,&\text{иначе}.
\end{cases}
$$

Второй запуск начинает с назначения всей массы каждого поля источнику с минимальным $D_{ij}$. Остальные начинаются со случайных неотрицательных весов, нормированных до суммы $q_j$ в каждом столбце. Случайность фиксируется `--seed`.

### 6.2. Градиент и пробный план

Обозначения:

- $G_{ij}$ — производная общей потери по элементу $T_{ij}$;
- $i_j^{\mathrm{trial}}$ — источник с минимальным градиентом среди допустимых для поля $j$;
- $V$ — пробный план, который отдаёт всю массу каждого поля выбранному источнику.

Для симметричных матриц связей текущая реализация использует:

$$
G_{ij}=\frac{\partial F}{\partial T_{ij}}
=(1-\alpha)D_{ij}
+2\alpha\sum_{k,l}(C^X_{ik}-C^Y_{jl})^2T_{kl}.
$$

$$
i_j^{\mathrm{trial}}\in\arg\min_{i\in\mathcal A_j}G_{ij},
\qquad
V_{ij}=\begin{cases}q_j,&i=i_j^{\mathrm{trial}},\\0,&\text{иначе}.\end{cases}
$$

Пробный источник выбирается по градиенту всей потери, а не только по паспортному различию. Один источник разрешено выбрать для нескольких полей.

### 6.3. Размер шага и остановка

Обозначения:

- $\gamma$ — доля перехода от текущего плана к пробному;
- $T_{\mathrm{new}}$ — обновлённый план;
- $g$ — Frank–Wolfe gap, используемый для остановки;
- $\mathrm{tol}$ — заданный порог остановки.

$$
g=\sum_{i,j}G_{ij}(T_{ij}-V_{ij}).
$$

При $g\le\mathrm{tol}$ запуск заканчивается; по умолчанию `--tol 1e-9`. Код ограничивает вычисленный gap снизу нулём из-за численных погрешностей.

Иначе выбирается шаг:

$$
\gamma^*\in\arg\min_{0\le\gamma\le1}F\bigl(T+\gamma(V-T)\bigr),
\qquad
T_{\mathrm{new}}=T+\gamma^*(V-T).
$$

Вдоль этого направления функция квадратичная: код проверяет концы отрезка и внутренний минимум, если он существует. При нулевом шаге запуск также останавливается. Иначе пересчитываются градиент и пробный план. Лимит по умолчанию — 300 итераций на запуск (`--max-iter 300`).

После всех запусков выбирается план с минимальным найденным $F(T)$. Задача невыпуклая. Статус `CONVERGED` означает выполнение критерия остановки, не гарантию глобального минимума или семантической правильности соответствий.

## Шаг 7. Получаем нормированные веса fgw_scores

Обозначение: $P_{ij}$ — нормированная масса назначения, записываемая в `fgw_scores.csv`.

$$
P_{ij}=\frac{T_{ij}}{\sum_kT_{kj}}=\frac{T_{ij}}{q_j}.
$$

Для активного поля сумма его столбца равна 1. Для поля без кандидатов столбец остаётся нулевым.

Например, план $T_B$ из шага 5 превращается в:

| Источник | $Y_1$ | $Y_2$ |
|---|---:|---:|
| $X_1$ | 1 | 0 |
| $X_2$ | 0 | 1 |

В этом случае вся масса каждого поля досталась одному источнику. Возможны и дробные значения: столбец плана `[0.3, 0.2]` при $q_j=0.5$ даёт `[0.6, 0.4]`.

Нули и единицы возникают в самом найденном плане, до финального выбора максимума. В текущей цели нет энтропийной регуляризации, которая поощряла бы распределение массы между кандидатами. Однако бинарность результата не является обязательным ограничением.

**Вес 1 не означает 100% вероятности правильности.** Он означает, что в найденном плане вся масса поля досталась одному источнику. $F(T)$ — одно число для всего плана; $P_{ij}$ — одна клетка матрицы назначений. Это разные величины.

## Шаг 8. Выбираем источник каждого поля и сохраняем результат

Обозначение: $i^*(j)$ — индекс окончательно выбранного источника для поля MBD $j$.

$$
i^*(j)\in\arg\max_{i\in\mathcal A_j}P_{ij}.
$$

При равенстве весов выбирается источник с меньшим паспортным различием $D_{ij}$; при повторном равенстве — по имени источника в лексикографическом порядке.

Пример результата:

```text
event_type ← col_2
src_type11 ← col_3
```

Повторные назначения одного источника сохраняются. Поля без допустимых кандидатов получают `unfilled`, в JSON — `null`.

Основные артефакты:

| Файл | Содержание |
|---|---|
| `xbank_profiles.csv`, `mbd_profiles.csv` | Паспорта колонок |
| `xbank_structure.csv`, `mbd_structure.csv` | Матрицы структурных расстояний |
| `xbank_structure_support.csv`, `mbd_structure_support.csv` | Число совместно валидных строк для каждой пары |
| `xbank_dependencies.csv`, `mbd_dependencies.csv` | Значения NMI и пригодность оценок связей |
| `distance.csv` | Матрица различий паспортов $D$; меньше — ближе. Для запрещённых по типу или гейтам пар 1 служит заполнителем; допустимость проверяется по маске |
| `allowed_pairs.csv` | Маска допустимых назначений |
| `transport_matrix.csv` | Найденный план $T$ |
| `fgw_scores.csv` | Нормированные веса $P$ |
| `solver.json` | Общая потеря, компоненты по запускам, история и критерий остановки |
| `mapping.csv`, `assignment_diagnostics.csv` | Назначения и их диагностика |
| `frozen_mapping.json` | Соответствие `mbd_to_xbank[поле MBD] = колонка xbank` |

Общий минимум потерь оценивает согласованность с выбранными критериями. Правильность соответствий проверяется отдельно на задачах с известным ответом, например MBD–MBD. Отрыв между двумя весами назначения сам по себе не доказывает надёжность: при плане с нулями и единицами он может быть равен 1 даже у ошибочного соответствия.

Стандартная постановка semi-relaxed FGW: [документация POT](https://pythonot.github.io/gen_modules/ot.gromov.html#ot.gromov.semirelaxed_fused_gromov_wasserstein). В обозначениях POT фиксирована сумма по строкам; в нашем коде матрица ориентирована наоборот и фиксирована сумма по столбцам MBD. Реализация здесь собственная, зависимость от POT не требуется.


## Запуск

Из каталога `xbank-transfer`:

```bash
PYTHONPATH=src python -m cross_schema.column_profiles_vFGW \
  --testbed-only \
  --testbed-variant folds \
  --sample-rows 2000000 \
  --structure-rows 200000 \
  --out-dir data/profiles_vFGW
```


Для переноса на другой сервер достаточно обновить `column_profiles_vFGW.py`: другие версии матчера ему не нужны. Файл можно запускать напрямую:

```bash
python src/cross_schema/column_profiles_vFGW.py \
  --testbed-only \
  --testbed-variant folds \
  --sample-rows 2000000 \
  --structure-rows 200000 \
  --out-dir data/profiles_vFGW
```

Данные должны находиться по указанным путям; при необходимости задайте `--mbd-root`, `--xbank-path` или `--daily-path`. Для тестбеда `daily` требуется уже подготовленный parquet: его эталонная схема описана локально в `DAILY_MBD_TO_XBANK`.
